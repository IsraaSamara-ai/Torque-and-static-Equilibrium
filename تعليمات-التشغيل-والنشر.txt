✅ الطريقة الأولى: التنزيل والاستخدام مباشرة (الأسهل)
───────────────────────────────────────────────
1. نزّلي ملف «الفيزياء-التفاعلية-العزم-والاتزان.html» إلى جهازك
   (حاسوب أو هاتف أو جهاز العرض الذكي).
2. اضغطي على الملف مرتين — يفتح في أي متصفح (Chrome / Edge / Safari).
3. لا يحتاج إنترنت ولا أي برنامج إضافي — كل شيء داخل الملف
   (الشرائح، الأسئلة التفاعلية، الأصوات، التعليق الصوتي، صور أينشتاين).
4. يمكنك مشاركته مع الطالبات عبر WhatsApp أو البريد الإلكتروني أو
   وحدة تخزين USB — كل طالبة تفتحه على جهازها وتجيب بنفسها!

💡 ملاحظات:
• الأصوات والتعليق الصوتي يبدآن بعد أول نقرة على الشاشة (سياسة المتصفحات).
• نتائج الطلبة والمجموعات تُحفظ تلقائيًا في المتصفح نفسه (localStorage)
  وتظهر في لوحة الصدارة، ويمكن للمعلمة تصفيرها بزر «تصفير».
• الأسئلة التفاعلية: الطالبة تنقر إجابتها فيتلون الخيار بالأخضر
  إذا كان صحيحًا، وبالأحمر إذا كان خاطئًا مع شرح فوري.

🌐 الطريقة الثانية: النشر على Netlify (رابط مباشر للطالبات)
───────────────────────────────────────────────
الطريق السريع (بدون حساب):
1. افتحي: https://app.netlify.com/drop
2. اسحبي مجلد «netlify» كاملًا وأفلتيه في الصفحة.
3. خلال ثوانٍ يعطيك رابطًا مباشرًا مثل:
   https://something.netlify.app
4. انسخي الرابط وأرسليه للطالبات — يفتح على أي جهاز.

بحساب مجاني (رابط ثابت باسمك):
1. سجّلي حسابًا مجانيًا في netlify.com
2. من لوحة التحكم: Add new site ← Deploy manually
3. اسحبي مجلد «netlify» — وستحصلين على رابط دائم يمكنك تسميته
   مثل: physics-torque.netlify.app

───────────────────────────────────────────────
🐍 الطريقة الثالثة: النشر على Streamlit Cloud
───────────────────────────────────────────────
1. أنشئي مستودعًا (Repository) على GitHub باسم مثل: physics-app
2. ارفعي فيه ملفات مجلد «streamlit» الثلاثة:
   • app.py
   • requirements.txt
   • index.html
3. ادخلي إلى: https://share.streamlit.io وسجّلي بحساب GitHub
4. اضغطي New app ← اختاري المستودع ← الملف الرئيسي: app.py
5. بعد دقائق يعطيك رابطًا مثل:
   https://your-name-physics-app.streamlit.app

أو للتشغيل المحلي عبر Streamlit:
   pip install -r requirements.txt
   streamlit run app.py

🎓 محتويات التطبيق (في كل النسخ)
───────────────────────────────────────────────
• نتاجات الدرس الخمسة
• عرض تقديمي: 15 شريحة تفاعلية + 12 سؤال «تحقّق سريع»
  (الطالبة تجيب ويظهر الأخضر/الأحمر فورًا)
• اشتقاق قانون العزم τ = rF sinθ في 6 خطوات بأسئلة تحقق
• مختبر تفاعلي: منزلقات r و F و θ مع مخطط متجدد وتحدي هدف
• الألعاب التنافسية:
  – تحدي البرق الفردي: 10 أسئلة × 30 ثانية، نقاط سرعة وسلاسل
    وأسلوب مساعدة (حذف خيارين + تخطي)
  – معركة المجموعات: 2-6 مجموعات، 8 جولات، آلية سرقة النقاط،
    الإجابة بالنقر (أخضر/أحمر) مع تحكيم يدوي احتياطي للمعلمة
• لوحة الصدارة: منصة تتويج + ترتيب الأفراد والمجموعات (محفوظة محليًا)
• مؤثرات صوتية تفاعلية + تعليق صوتي عربي بصوت أينشتاين الكرتوني
• شخصية أينشتاين الكرتونية ترافق كل قسم للتشويق والتحفيز
